Pop!_OS is an impressive Linux distribution that’s user-friendly, powerful, and based on Ubuntu. Developed by System76, it features a customized GNOME desktop environment, supports both AMD and NVIDIA GPUs, and is known for working seamlessly on a wide range of hardware. In fact, I have it installed on a 2015 Macbook Pro and a 2020 Razor Blade 15. The only modifications I had to make, was changing a few keyboard shortcuts to compensate for the Macbook keyboard and Windows functions keys. This is how I further customize and setup my Pop!_OS laptops.

Once Pop!_OS is installed and the initial one-time setup is complete, I click "Start Using Pop!_OS" and conduct the following:


## Step 1 - Update Machine and Customize Terminal

1. Open **Terminal > Preferences > Pop**.
2. Change Columns to **110**, click **Colors** and check **Use colors from system theme**.
3. Close and re-launch Terminal.
4. Run the following commands in the Terminal, pressing Enter after each one:
5. `sudo apt update`
6. `sudo apt upgrade -y`
7. `sudo pop-upgrade recovery upgrade from-release`
8. `sudo pop-upgrade release upgrade`
9. `sudo apt autoremove -y`
10. `sudo apt autoclean -y`
11. `sudo flatpak update -y`
12. Add padding to the Terminal:
13. Type `cd .config/gtk-3.0` > **enter**.
14. Type `touch gtk.css` > **enter**.
15. Type `nano gtk.css` > **enter**.
16. Type `vte-terminal { padding: 17px }` > **ctrl + o** > **enter** > **ctrl x**.


## Step 2 - Adjust Settings Form The GUI

1. Open **Settings**.
2. In the left menu, click **Bluetooth** and toggle it off. 
3. Click **Privacy** in the left menu and disable **Connectivity Checking**.
4. Click **File History & Trash** and disable everything.
5. Click **Screen** and change **Blank Screen Delay** to a longer time.
6. Go back to the main screen, click **Power** and disable **Automatic Screen Brightness** and **Dim Screen**.
7. Click **Automatic Suspend** and disable all options.
8. Enable **Show Battery Percentage**.
9. Go back to the main screen, click **Mouse & Touchpad** and increase **Touchpad Speed**.


## Step 3 - Adjust Settings From The Terminal

1. Change icon size:
2. Type `gsettings set org.gnome.shell.extensions.dash-to-dock dash-max-icon-size 40` > **enter**.
3. Enable permanent file deletion:
4. Type `gsettings set org.gnome.nautilus.preferences show-delete-permanently true` > **enter**.
5. Show all hidden files:
6. Type `gsettings set org.gnome.nautilus.preferences show-hidden-files true` > **enter**.
7. Type `gsettings set org.gtk.Settings.FileChooser show-hidden true` > **enter**.
8. Install the COSMIC Store and remove the POP Shop:
9. Type `sudo apt install cosmic-store -y` > **enter**.
10. Type `sudo apt remove pop-shop --purge -y` > **enter**.


## Step 4 - Install And Download Customizing Assets

1. Open **COSMIC Store**, search for **GNOME Tweaks**, click **Install**.
2. Open **COSMIC Store**, search for **Extension Manager**, click **Install**. 
3. Visit https://draculatheme.com/gtk and download the zip file.
4. Visit https://www.gnome-look.org/p/1253385 and click **Download** > **Sweet-Dark-v40.tar.xz**.
5. Visit https://www.gnome-look.org/p/1332404 and click **Download** > **Flatery-Indigo.tar.gz**.
6. Visit https://www.gnome-look.org/p/1355701 and click **Download** > **McMojave-cursors.tar.xz**


## Step 5 - Prepare For Customization

1. Open **Files** and create two folders in the **Home** directory, **.themes** and **.icons**.
2. Extract **gtk-master.zip** and **Sweet-Dark-v40.tar.xz** into the **.themes** directory.
3. Rename the extracted folder **gtk-master** to **Dracula**.
4. Extract **McMojave-cursores.tar.xy** and **Flatery-Indigo.tar.gz** into the **.icons** directory.
5. Remove the two folders form the **Flatery-Indio** folder and place them in the **.icons** directory.


## Step 6 - Customize Pop!_OS

Open **Extension Manager**, then click **Browse**. Search for the following extensions and click **Install** next to each one:

- User Themes
- Blur My Shell
- Compiz Windows Effect
- Burn My Windows
- Logo Menu
- Privacy Quick Settings
- Top Bar Organizer

1. Open **GNOME Tweaks** > **Appearance**, change Applications to **Dracula**.
2. Change Cursor to **McMojave-cursors**.
3. Change Icons to **Flatery-Indigo**.
4. Change Shell to **Sweet-Dark-v40**.


That's it. Now all I have to do is use the COSMIC Store to install the applications I want to use. You can use other applications to install the extensions, but I have found only the Flatpak versions work correctly.  Let me explain the extensions and what they do.

- User Themes - This allows GNOME Tweaks to apply themes, icons and shell changes.
- Blur my shell - Gives a blur effect to the top panel, dash, and overview.
- Compiz - Adds a wobbly window effect when moving windows.
- Burn My Windows - Disintegrate your windows with style. (I love the Hexagon effect)
- Logo Menu - Gives a Mac like icon in the top bar to access the settings and info about your system. (I use the Tux icon)
- Privacy Quick Settings - Gives toggle switches to top bar for location, camera, and microphone.
- Top Bar Organizer - Lets you organize the icons on the top bar.

This is how I set up my machines. You can use some or all my suggestions to customize your Pop!OS installation. Or even better, now that you know how to customize Pop!_OS (or any GNOME desktop environment), find something you like and make your desktop environment all yours.

dconf reset -f /
